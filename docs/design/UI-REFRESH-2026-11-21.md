## القرار والنطاق

CONFIRMED: اعتمد صاحب المشروع الخيار الأول: مساحة إدارية بالأزرق والكحلي، عربية RTL وإنجليزية LTR، مع تنقّل واضح للحاسوب والهاتف. التقنيات والمصادقة وقاعدة البيانات والصلاحيات محفوظة. جميع الأدوات والموارد مجانية. لا حسابات خدمات جديدة ولا رسوم.

الملفات تشمل اللوحة الرئيسية والدخول وقوائم الطلاب والفصول، ومكونات التنقل والأزرار والخطوط والترجمة والاختبارات. بقية الوحدات تعمل بروابطها القائمة، ولا يدّعي هذا التحديث إعادة تصميم كل شاشة في النظام.

- Noto Sans Arabic وInter: خطوط ذاتية الاستضافة عبر Fontsource، رخصة OFL. نسخ الرخص ضمن licenses/. لا تحميل من طرف ثالث عند زيارة الصفحات.

- الخلفيات والرسمة الزخرفية: CSS وتركيب أيقونات محلي، بلا صور أطفال أو وجوه أو صور مخزنة توحي بطلاب حقيقيين.

مصادر مقترحة للمشاريع التالية، وليست حسابات موصولة أو عناصر مستخدمة كلها هنا:

- Uiverse Galaxy: عناصر CSS/Tailwind مفتوحة، MIT. مراجعة كل عنصر وأثر الحركة والإتاحة قبل النقل، والاحتفاظ بإشعار الرخصة. https://github.com/uiverse-io/galaxy/
- Haikei Basic: مولد خلفيات مجاني بلا حساب، مع استخدام شخصي وتجاري وصادرات SVG/PNG ضمن الحدود المعلنة. لا إعادة بناء خدمة مولد منافسة من أصوله. https://haikei.app/pricing/
- Pexels: صور مجانية ضمن الرخصة، مع منع الإيحاء بتأييد الأشخاص أو العلامات أو إعادة بيع الصور غير المعدلة. يراجع الأصل المحدد قبل استخدامه. https://www.pexels.com/license/
- Unsplash: تنزيلات الصور العادية تختلف عن شروط API. تكامل API يتطلب نسبة الصورة لصاحبها وUnsplash وروابطهما، وروابط الصور الرسمية وتسجيل التنزيلات وحماية المفاتيح. لا حاجة لهذا التكامل في لوحة المدارس. https://unsplash.com/license و https://help.unsplash.com/en/articles/2511245-unsplash-api-guidelines

الترخيص المجاني لا يعني إسقاط إشعارات حقوق النشر أو حقوق الأشخاص والعلامات. لا اشتراكات أو تجارب مدفوعة. لم تُثبت إضافات محرر جديدة ولم يُدّع تفعيل وكلاء مستقلة أو MCP لمجرد قراءة المواقع.

## الاختبار والأمان

- اختبارات Unit: تنقّل الأدوار، روابط اللغات، تطابق مفاتيح العربية والإنجليزية، مع مجموعة اختبارات المصادقة والصلاحيات القائمة.
- Integration: عرض هيكل الصفحة من الخادم لكل دور، الهروب الآمن لأسماء المدرسة والمستخدم، وربط محتوى الصفحة والتنقل.
- Browser: دخول محلي بحساب fixture، تنقّل الهاتف، تبديل اللغة مع حفظ الصفحة، منع دخول صفحة الطلاب بلا جلسة، وعدم تجاوز عرض الصفحة على 320 و768 و1440 بكسل.
- فحص axe آلي لمعايير WCAG A/AA على لوحات العربية والإنجليزية وقوائم الطلاب والفصول على الهاتف والحاسوب، وعلى الدخول. لا يعادل تدقيق إتاحة بشري شامل.
- تشغيل محلي معزول: UI_TEST_FIXTURE=1 npm run test:browser. يُنسخ المشروع إلى مجلد مؤقت، وتوضع بيانات الاختبار هناك فقط، ثم يحذف. لا مسار تجاوز مصادقة في كود الإنتاج، ولا كتابة طلاب أو فصول حقيقيين. يسبق التشغيل npm ci ثم npx playwright install chromium.
- إصلاح تحذير Next.js 15 الفعلي: await requestLocale في إعداد next-intl بدلاً من القراءة المتزامنة القديمة. لم يتم إخفاء التحذير فقط.
- تحديث Next.js وeslint-config-next إلى تصحيح 15.5.29 ضمن الإصدار الرئيسي القائم لتجنب مشاكل أمنية معروفة في التصحيح السابق. لا تغيير إطار عمل أو معمارية.
- مراجعة التهديدات: لا تغييرات على تفويض الخادم أو API أو مخطط البيانات؛ لا HTML غير موثوق أو أرقام نشاط وهمية؛ أسماء المستخدم/المدرسة تمر عبر هروب React؛ التنقل ليس بديلاً عن التحقق الخادمي.
